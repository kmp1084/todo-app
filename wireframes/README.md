# Wireframes

Low-fidelity mockups — they show **layout and structure**, not final colors, fonts, or
Material styling. The goal is to agree on *what goes where* before writing Angular.

| File                | Screen                                             |
| ------------------- | -------------------------------------------------- |
| `main-screen.html`  | The single task screen: add form, filters, list    |
| `auth-screen.html`  | Login / register (Phase 4)                          |

Open any file in a browser to view. Annotations (dashed callouts) explain intent.
